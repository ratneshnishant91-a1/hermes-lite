# Hermes-Lite v2.5.1: durable learning foundation

Hermes-Lite v2.5.1 adds evidence-first infrastructure for improving an agent harness without autonomous code modification.

## Components

- **Run event log:** `EventLog` persists append-only events to `workspace/runs/events.jsonl`. Each event has a run ID, timestamp, kind, message, and optional success signal. Writes call `sync_data` so completed events survive normal process termination.
- **Failure analysis:** `learning::analyze` groups normalized failed events into stable signatures and emits deterministic repair suggestions. It proposes changes; it never applies them.
- **Harness manifest:** `HarnessStore` stores versioned policy manifests in `workspace/harness/`. A manifest records prompt policy, allowed tools, memory policy, and notes. Previous versions can be restored explicitly.

## Why this design

Recent agent-memory and self-improvement research emphasizes retaining evidence and provenance, consolidating observations rather than unbounded transcripts, and making harness changes measurable and reversible. This release implements the safe infrastructure needed for that workflow: durable evidence, deterministic analysis, versioned policy state, and regression tests.

## Safe improvement loop

1. Run a task and record the trajectory/event evidence.
2. Inspect failure clusters with an operator or evaluator.
3. Add a regression test for the desired correction.
4. Revise a harness manifest deliberately.
5. Compare results and explicitly roll back if the revision regresses behavior.

The core runtime remains local-first: no network capability or autonomous production changes are enabled by this release.
